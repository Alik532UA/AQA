# AGENTS.md — AQA Interview Dashboard

> **Спершу прочитай [PROJECT-CONTEXT.md](PROJECT-CONTEXT.md).** Там зафіксовано архітектурні інваріанти, модель даних слайдів, стандарти безпеки та матрицю якості. Цей файл — практична витримка для повсякденної роботи агентів.

---

## 1. Що це за проєкт

Інтерактивний веб-дашборд та презентаційна база знань для підготовки до технічних співбесід QA:

- **Категорії**: `M` (Manual QA), `A` (Automation QA .NET/C#), `C` (Senior Consultant Desktop/Windows), `F` (Middle QA Flutter/Nayax).
- **Стек**: SvelteKit 3 + Svelte 5 (Runes), Tailwind CSS 4, TypeScript 6, `@sveltejs/adapter-static`.

---

## 2. Ключові інваріанти

1. **Svelte 5 Runes**: Використовувати виключно синтаксис Runes (`$state`, `$derived`, `$props`, `$effect`, snippets). Жодного застарілого Svelte 4 API.
2. **Безпека XSS**: Заборонено рендерити незахищений сирий HTML через `{@html}`. Текст завжди повинен проходити функцію `escapeHtml()` перед підсвіткою.
3. **Цілісність даних**: При додаванні нових слайдів або категорій обов'язково зберігати структуру існуючих карток та типів.
4. **Контроль якості**: Будь-які зміни обов'язково верифікуються командами `npm run check && npm run lint && npm test && npm run build`.

---

## 3. Локальні пастки

| Пастка                           | Що врахувати                                                                                                                                       |
| :------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Експорт слайдів у Markdown**   | Після додавання нових слайдів до `slidesData.ts` потрібно запускати `node ./scripts/export_all_slides.js`, щоб оновити файли в папці `slides-md/`. |
| **Відкритість кодових снипетів** | Усі приклади коду (C#, Dart, SQL) у картках мають бути синтаксично правильними та готовими до демонстрації на співбесідах.                         |
| **Tailwind 4**                   | Використовується `@tailwindcss/vite`. Конфігурація живе безпосередньо в CSS файлі `src/routes/layout.css`, без окремого `tailwind.config.js`.      |

---

## 4. НЕ РОБИ

- **НЕ** використовуй `{@html}` без санітизації через `escapeHtml`.
- **НЕ** ламай сумісність типів у `src/lib/types.ts` або `src/lib/data/slidesData.ts`.
- **НЕ** залишай невідформатований код — запускай `npm run format`.
- **НЕ** роби комітів без проходження перевірок `npm run check` та `npm test`.
