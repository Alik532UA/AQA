## Технічні запитання (Electron, Windows & Інструменти)

**Q1: Як Playwright запускає та контролює Electron?**
Playwright використовує модуль `_electron.launch()`, підключаючись до додатка через Chrome DevTools Protocol (CDP). Він отримує об'єкт головного процесу та чекає на перше вікно через `firstWindow()`, відкриваючи повний доступ до DOM і контексту рендерера.

**Q2: Як протестувати взаємодію з системним треєм?**
Трей є нативним елементом оболонки Windows (Shell_TrayWnd). Для його перевірки використовуємо FlaUI (C#), знаходимо область сповіщень через UIA3 та викликаємо контекстні меню правою кнопкою миші.

**Q3: Як автоматизувати перевірку Application Upgrade?**
Через пайплайн у 3 кроки: 1) Тиха інсталяція старої версії N + створення мерчант-сесії; 2) Запуск інсталятора версії N+1; 3) Запуск оновленого додатку та перевірка, що сесія збережена, а міграція БД успішна.

## Консалтингові та інфраструктурні запитання

**Q4: Чому WinAppDriver більше не рекомендується?**
Проект фактично заморожений Microsoft, погано працює на Windows 11 та multi-DPI, вимагає запуску окремого сервера. FlaUI є сучасною бібліотекою на C#, що працює безпосередньо з UIA3 без зайвих прошарків.

**Q5: Як вирішити проблему чорних екранів на Windows CI?**
Не запускати CI-агент як Windows Service (Session 0). Запустити агента в інтерактивній сесії користувача з автологіном (AutoLogon) та віртуальним дисплеєм 1920x1080.

**Q6: Яка стратегія за 3-4 тижні консалтингу?**
Аудит прогалин (тиждень 1) → Архітектура та вибір стеку (тиждень 2) → 3 робочі PoC (тиждень 3) → Windows CI пайплайн, ADR та передача команді (тиждень 4). Залишити працюючий інструмент, а не просто теорію.
