# Типи даних & Базовий синтаксис

> **Підтеми:** CTS типи, розрядність, арифметичні оператори, ++i vs i++, логічні оператори & vs &&

**Категорія:** C# Core & Advanced (.NET)

---

## Вбудовані типи даних C# (CTS / CLR)

Усі типи в C# базуються на єдиній системі **Common Type System (CTS)** платформи .NET і поділяються на типи значень (Value Types) та посилальні типи (Reference Types).

### Основні примітивні типи та їх розрядність:

**Цілочисельні:**
`byte` (8-bit, 0..255), `sbyte` (8-bit зі знаком), `short` / `ushort` (16-bit), `int` / `uint` (32-bit, ~±2.14 млрд), `long` / `ulong` (64-bit).

**Числа з рухомою комою та точністю (IEEE 754):**

- `float` (32-bit Single, суфікс `f`, ~7 знаків точності) — графіка, низька точність.

- `double` (64-bit Double, за замовчуванням, ~15-16 знаків точності) — загальні математичні розрахунки.

- `decimal` (128-bit, суфікс `m`, 28-29 знаків точності) — фінансові та грошові операції (виключає похибки двійкового округлення).

**Логічний, символьний та рядковий:**

- `bool` (1 байт у пам'яті CPU/масивах, логічно 1 біт, при вирівнюванні структури може займати 4 байти; значення `true` / `false`).

- `char` (2 байти, одиночний символ UTF-16, в одинарних лапках `'A'`).

- `string` (Reference type, **immutable** — незмінний масив UTF-16). Будь-яка модифікація виділяє новий об'єкт у Heap (у циклах застосовуйте `StringBuilder`). Рядкові літерали зберігаються у **String Intern Pool** (повторні однакові рядки посилаються на одну область пам'яті).

**Спеціальні значення double/float:** Ділення на `0.0` не кидає виняток, а повертає `PositiveInfinity`, `NegativeInfinity` або `NaN` (0.0 / 0.0).

**Пастка NaN:** `double.NaN == double.NaN` завжди повертає `false`! Для перевірки використовуйте виключно `double.IsNaN(val)`.

## Оператори, інкремент/декремент та логіка

### Арифметичні оператори та інкремент:

Базові: `+`, `-`, `*`, `/` (цілочисельне ділення при цілих операндах!), `%` (залишок від ділення).

**Префіксний vs Постфіксний інкремент:**

```csharp
int a = 5;
int b = a++; // b = 5, a = 6 (повертає старе значення, ПОТІМ додає 1)
int c = ++a; // c = 7, a = 7 (спочатку додає 1, ПОТІМ повертає)
```

**Пастка співбесіди:** Вираз `i = i++;` залишає значення `i` незмінним (постфіксний оператор кешує старе значення, інкрементує `i`, а оператор `=` повертає в `i` старе закешоване значення).

### Порівняння та логічні оператори:

- **Оператори порівняння:** `==`, `!=`, `>`, `<`, `>=`, `<=` (повертають `bool`).

- **Логічне "І":** `&&` (Short-circuit / коротке замикання) vs `&` (повне/бітове обчислення). Якщо у `expr1 && expr2` перший вираз `false`, другий навіть НЕ обчислюється!

- **Логічне "АБО":** `||` (коротке замикання) vs `|` (повне/бітове обчислення). Якщо у `expr1 || expr2` перший вираз `true`, другий не викликається.

**Фокус для інтерв'ю:** «Коротке замикання `&&` критично важливе для уникнення падінь: `if (element != null && element.Displayed)` ніколи не кине `NullReferenceException`, тоді як `&` обов'язково кине виняток».
