# Наслідування, Поліморфізм, Abstract & Interfaces

> **Підтеми:** : base, virtual, override, new, abstract class vs interface, явна та дефолтна реалізація

**Категорія:** C# Core & Advanced (.NET)

---

## Наслідування, : base & Поліморфізм (virtual/override)

### Наслідування (Inheritance):

Створення нових класів на основі існуючих. У C# підтримується **виключно одинарне наслідування класів** (але множинна реалізація інтерфейсів).

```csharp
public class LoginPage : BasePage {
    // Виклик конструктора базового класу через : base(...)
    public LoginPage(IWebDriver driver) : base(driver) { }
    
    public override void Open() {
        base.Open(); // Виклик базової реалізації
        NavigateTo("/login");
    }
}
```

### Поліморфізм: virtual, override та new:

**virtual / override (Динамічний поліморфізм):**
`virtual` дозволяє перевизначити метод. `override` замінює реалізацію у vtable. Виклик через базове посилання `BasePage page = new LoginPage(); page.Open();` виконає версію `LoginPage`.

**new (Method Hiding — приховування):**
Розриває віртуальність. Виклик через посилання базового типу виконає *базовий* метод; виклик через тип спадкоємця — новий прихований метод.

**Порядок ініціалізації:** Спочатку ініціалізуються поля похідного класу -> викликається конструктор базового класу (`Base`) -> виконується тіло конструктора похідного класу (`Derived`).

## Abstract Class vs Interface

### Порівняння Abstract Class та Interface:

| Властивість | Abstract Class | Interface |
| :--- | :--- | :--- |
| Сутність | Відношення **"IS-A"** (спільна базова сутність) | Відношення **"CAN-DO"** (контракт поведінки) |
| Множинність | Клас може наслідувати лише **1** клас | Клас або структура може реалізувати **безліч** інтерфейсів |
| Стан (Поля) | Може мати поля екземпляра (`private`, `protected`) | Не може мати полів екземпляра (лише властивості/події) |
| Конструктори | Має конструктори (викликаються через `: base()`) | Не має конструкторів екземпляра |

### Явна та дефолтна реалізація інтерфейсів:

**Явна реалізація (Explicit Implementation):**
Вирішує колізію двох інтерфейсів з однаковим методом: `void IApiTest.Run() { ... }`. Метод доступний **тільки при приведенні об'єкта до інтерфейсу**: `((IApiTest)test).Run();`.

**Default Interface Methods (C# 8+):**
Інтерфейс може містити дефолтне тіло методу. Це дозволяє розширювати контракт без ламання існуючих реалізацій.

**Структури (struct) та Інтерфейси:** Структури можуть реалізовувати інтерфейси, але приведення екземпляра структури до інтерфейсу (`IDisposable d = myStruct;`) викликає **Boxing** у Heap!
