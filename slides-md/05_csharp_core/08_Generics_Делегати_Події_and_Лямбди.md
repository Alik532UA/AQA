# Generics, Делегати, Події & Лямбди

> **Підтеми:** Generic constraints (where), delegate, Action, Func, Predicate, event, лямбди =>

**Категорія:** C# Core & Advanced (.NET)

---

## Generics (Узагальнення) & Обмеження (Constraints)

**Generics** дозволяють створювати класи, методи та інтерфейси, параметризовані типами даних. Вони забезпечують безпеку типів (Type-Safety) під час компіляції та виключають накладні витрати на boxing/unboxing.

### Обмеження типів (Generic Constraints) через where:

`where T : class` — тип `T` зобов'язаний бути посилальним типом (Reference Type).

`where T : struct` — тип `T` зобов'язаний бути типом значення (Value Type).

`where T : new()` — вимагає наявності публічного конструктора без параметрів (дозволяє писати `new T()`).

`where T : BasePage` — тип повинен наслідувати вказаний клас.

`where T : IDisposable` — тип повинен реалізувати конкретний інтерфейс.

### Практичний AQA патерн фабрики сторінок:

```
public T InitPage<T>() where T : BasePage, new() {
    var page = new T();
    page.SetDriver(this.Driver);
    return page;
}
```

## Делегати, Func, Action, Події (Events) & Лямбди

### Делегати (Delegates):

Делегат — це тип безпечного покажчика на метод (сигнатура методу). Дозволяє передавати методи як аргументи в інші методи.

### Стандартні делегати .NET (Action vs Func):

**Action<T1, T2...>:**
Приймає від 0 до 16 аргументів і **НЕ повертає значення (void)**.

`Action<string> log = msg => Console.WriteLine(msg);`

**Func<T1, T2..., TResult>:**
Приймає аргументи та **ОБОВ'ЯЗКОВО повертає результат**. Останній тип у списку є типом повернення!

`Func<int, int, bool> isGreater = (a, b) => a > b;`

**Predicate<T>:**
Аналог `Func<T, bool>` для перевірки умов у пошуку та фільтрації.

### Події (Events) та їх захист:

Подія (`event`) — це обгортка над делегатом (патерн Publisher-Subscriber):

```
public event Action<TestResult> OnTestFinished;
```

**Різниця між публічним делегатом та подією:** Подію зовнішній код може лише підписувати (`+=`) або відписувати (`-=`). Викликати подію або занулити (`= null`) можна **виключно всередині класу-власника**.
