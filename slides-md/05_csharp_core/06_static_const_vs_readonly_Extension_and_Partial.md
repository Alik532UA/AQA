# static, const vs readonly, Extension & Partial

> **Підтеми:** Статичні члени та класи, const vs readonly, методи розширення, partial класи

**Категорія:** C# Core & Advanced (.NET)

---

## Модифікатор static та Статичний конструктор

Ключове слово **static** означає, що член або клас належить безпосередньо **самому типу**, а не конкретному екземпляру в пам'яті. Статичні члени існують в одному екземплярі на весь домен додатку.

### Особливості статичних конструкцій:

**static поля та методи:**
Викликаються через ім'я класу: `ConfigurationReader.GetBaseUrl()`. Не мають доступу до ключового слова `this`, оскільки існують поза контекстом екземпляра.

**static class:**
Містить *лише* статичні члени, не може створюватися через `new`, є неявно `sealed` і не може наслідуватися. Застосовується для утиліт та Extension методів.

**Статичний конструктор (static Constructor):**
`static DriverFactory() { ... }`. Не приймає аргументів, не має модифікаторів доступу. Викликається автоматично середовищем CLR **рівно один раз** перед першим зверненням до класу. Потокобезпечний за специфікацією CLR.

**Пастка для AQA:** У паралельних тестах статичні змінні (наприклад, `public static IWebDriver Driver`) призводять до перезапису драйвера між потоками (Race Condition). Застосовуйте `ThreadLocal<IWebDriver>` або DI-контейнер!

## const vs readonly, Extension Methods & partial

### Топ-питання співбесіди: const vs readonly:

| Критерій | const (Compile-time) | readonly (Runtime) |
| :--- | :--- | :--- |
| Момент ініціалізації | Під час компіляції (значення жорстко вшивається в IL-код) | Під час виконання програми (в оголошенні або в конструкторі) |
| Дозволені типи | Примітиви, `string`, `enum` або `null` для Reference-типів | Будь-які типи даних (включно з об'єктами `new ...`) |
| Контекст та пам'ять | Неявно статична (`static` заборонено), можна оголосити локально в методі | Тільки поле класу (інстансне або `static readonly`) |

**Пастка інтерв'ю з readonly для Reference Types:**
Якщо поле оголошено як `private readonly List<string> _logs = new();`, ми **не можемо** присвоїти йому новий список поза конструктором (`_logs = new()`), але ми **можемо** вільно модифікувати вміст об'єкта (`_logs.Add("Error")`, `_logs.Clear()`)!

### Extension Methods (Методи розширення):

Дозволяють додавати методи до існуючих типів без модифікації їхнього коду (ключове слово `this` у першому параметрі):

```csharp
public static class WebElementExtensions {
    public static void ClickWithWait(this IWebElement element, int timeout = 10) {
        // Очікування клікабельності та клік
    }
}
// Використання: submitButton.ClickWithWait();
```

**partial класи:** дозволяють розділити визначення класу на кілька файлів `.cs` (збираються компілятором в один тип). Застосовуються в Source Generators та автозгенерованому коді.
