# static, const vs readonly, Extension & Partial

> **Підтеми:** Статичні члени та класи, const vs readonly, методи розширення, partial класи

**Категорія:** C# Core & Advanced (.NET)

---

## Модифікатор static та Статичний конструктор

Ключове слово **static** означає, що член або клас належить безпосередньо **самому типу**, а не конкретному екземпляру в пам'яті. Статичні члени створюються в одному екземплярі на весь домен додатку.

### Особливості статичних конструкцій:

**static поля та методи:**
Викликаються через ім'я класу: `ConfigurationReader.GetBaseUrl()`. Не мають доступу до ключового слова `this`, оскільки викликаються поза контекстом екземпляра.

**static class:**
Може містити *лише* статичні члени, не може створюватися через `new`, є неявно `sealed` і не може наслідуватися. Використовується для утиліт (Math) та Extension методів.

**Статичний конструктор (static Constructor):**
`static DriverFactory() { ... }`. Не приймає параметрів, не має модифікаторів доступу. Викликається автоматично середовищем CLR **рівно один раз** перед першим зверненням до класу. Потокобезпечний за специфікацією CLR.

**Пастка для AQA:** У паралельних тестах статичні змінні (наприклад, `public static IWebDriver Driver`) призводять до перезапису драйвера між потоками (Race Condition). Використовуйте `ThreadLocal<IWebDriver>` або DI-контейнер!

## const vs readonly, Extension Methods & partial

### Топ-питання співбесіди: const vs readonly:

Критерій
const (Compile-time)
readonly (Runtime)

Момент ініціалізації
При компіляції (значення жорстко вшивається в IL)
Під час виконання програми (в оголошенні або конструкторі)

Дозволені типи
Тільки примітиви та `string`
Будь-які типи (включно з об'єктами класів)

Контекст
Неявно статична (`static` заборонено)
Може бути інстансною або `static readonly`

### Extension Methods (Методи розширення):

Дозволяють додавати методи до існуючих типів без їх модифікації. Оголошуються як статичний метод у статичному класі з ключовим словом `this` перед першим параметром:

```
public static class WebElementExtensions {
    public static void ClickWithWait(this IWebElement element, int timeout = 10) {
        // Логіка очікування клікабельності та клік
    }
}
// Використання в коді: submitButton.ClickWithWait();
```

**partial класи та методи:** дозволяють розділити опис одного класу на декілька файлів `.cs` (збираються компілятором в один тип). Застосовуються в автогенерації коду (Source Generators, Entity Framework).
