## CI/CD Практики: Поглиблений огляд для Middle Automation Test Engineer (.NET)

CI/CD (Неперервна інтеграція та Неперервна доставка/розгортання) – це сукупність практик у розробці ПЗ, які дозволяють автоматизувати процес створення, тестування та розгортання додатків. Невід'ємна частина сучасного DevOps.

### Неперервна Інтеграція (CI)

- **Часте об’єднання змін:** Розробники інтегрують зміни до основної гілки декілька разів на день.

- **Автоматизоване тестування:** Кожна інтеграція запускає набір тестів (юніт, інтеграційні) для швидкого виявлення проблем.

- **Швидкий зворотний зв’язок:** Негайний відгук про якість змін для оперативного виправлення.

Переваги CI: Раннє виявлення помилок, покращення якості коду, збільшення пропускної здатності команди.

### Неперервна Доставка (CD)

- **Автоматизоване розгортання:** Після успішних тестів зміни автоматично розгортаються на середовище, готове до виробництва.

- **Ручне затвердження:** Перед релізом на прод може знадобитися ручне затвердження.

### Неперервне Розгортання (CD)

- **Автоматичний реліз на продакшен:** Зміни розгортаються на бойове середовище без ручного втручання.

- Вимагає дуже високого рівня автоматизації тестів та моніторингу.

## Інструменти та важливі аспекти CI/CD (.NET)

### Переваги CD:

- Швидкий вихід на ринок, зменшення ризику розгортання, покращення користувацького досвіду.

### Ключові Інструменти CI/CD:

- **Системи контролю версій:** Git, SVN

- **Сервери CI:** Jenkins, GitLab CI/CD, CircleCI, Azure DevOps

- **Контейнеризація та оркестрація:** Docker, Kubernetes

- **Інструменти тестування:** NUnit, xUnit, Selenium, Playwright, Jest

- **Інфраструктура як код:** Terraform, Ansible

### Як CI/CD пов’язаний з .NET:

- .NET Core/8+: легко розгортається у Docker-контейнерах на Linux та Windows.

- NuGet для управління залежностями, MSBuild для збірки проектів, Azure DevOps як повноцінна платформа.

### Важливі Аспекти для Middle Automation Engineer:

- Розуміння конвеєра CI/CD, інтеграція запусків автотестів у пайплайн, аналіз артефактів звітів та блокування релізу при падіннях.
