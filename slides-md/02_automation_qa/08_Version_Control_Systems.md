## Git: Швидкий та гнучкий розподілений контроль версій

Git - це легка та швидка розподілена система контролю версій, що керує змінами за допомогою команд і підтримує нелінійні розподілені процеси.

### Основні переваги Git:

- **Розподілений характер:** кожен розробник має повну локальну копію репозиторію.

- **Ефективність:** висока швидкість роботи навіть у великих репозиторіях.

- **Гнучкість:** легке створення гілок, злиття та експерименти.

- **Надійне відстеження:** фіксація кожного коміту та автора змін.

### Ключові команди Git:

**git init:** ініціалізує новий локальний репозиторій.

**git clone <url>:** клонує віддалений репозиторій.

**git add:** додає змінені файли до індексу (staging).

**git commit -m "...":** фіксує збережені зміни в історію.

**git push / git pull:** відправка та отримання змін із сервера.

**git branch / checkout:** перегляд, створення та перемикання гілок.

**git merge:** злиття змін гілок.

---

## Корисні команди та приклад робочого процесу

### Інші корисні команди Git:

**git status:** стан робочого каталогу та індексу.

**git diff:** різниця між поточною версією та індексом.

**git log:** історія комітів.

**git reset --hard:** відкат змін до вказаного коміту.

**git tag:** позначення релізу або конкретного коміту тегом.

**git stash:** тимчасове відкладення незавершених змін.

### Приклад простого робочого процесу (Workflow):

- git clone https://github.com/org/repo.git

- git branch feature-login && git checkout feature-login

- git add .

- git commit -m "Додав нові автотести"

- git push origin feature-login

- Створення Pull Request для рев'ю
