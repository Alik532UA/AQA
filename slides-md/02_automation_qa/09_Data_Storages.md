## Робота зі сховищами даних для Automation QA (.NET)

Розуміння роботи з даними є ключовим для успішного автоматизованого тестування, особливо в .NET розробці.

### Data Storages (Сховища даних):

Місця, де зберігаються дані: бази даних, файли, хмарні сховища.

- **Реляційні бази (SQL):** таблиці, зв'язки, зовнішні/первинні ключі, транзакції.

- **Нереляційні бази (NoSQL):** JSON, графові, документні (MongoDB, Redis).

- **Хмарні сховища:** AWS S3, Azure Blob Storage, Google Cloud Storage.

- **Файлові системи:** локальні та мережеві директорії.

### SQL та NoSQL:

- **SQL:** SELECT, INSERT, UPDATE, DELETE, JOIN, агрегатні функції.

- **NoSQL:** ключ-значення, документні та графові моделі даних, швидкість читання.

## Data Warehouses, Test Data Management та підготовка

### Familiarity with Data Warehouses (Сховища даних):

- **OLAP:** багатовимірні моделі даних, агрегація великих обсягів інформації.

- **ETL:** процес завантаження даних (Extract, Transform, Load).

- Star Schema, Snowflake Schema.

### Test Data Management (Управління тестовими даними):

- Генерація випадкових даних, клонування реальних знеособлених даних.

- Очищення даних після виконання тестів (DB cleanup).

- Маскування чутливих персональних даних (GDPR, PCI-DSS).

- Інструменти: Bogus, Faker, SQL Server Data Generator.

### Як підготуватися до співбесіди:

- Повторіть теорію SQL, напишіть типові запити з JOIN та GROUP BY.

- Підготуйте приклади з реального досвіду роботи з БД у тестах.
